Dance Central 3
=============

A decompilation of Dance Central 3 (build Sep 16 2012) for the Xbox 360.

This repository does **not** contain any game assets or assembly whatsoever. An existing copy of the game is required.

This specfic fork is made as fun experiment just to see if the decompiled code will compile for 360 using XDK libraries.


Building
--------

- Install Visual Studio 2010 Ultimate
- Install the Xbox 360 SDK
- Open the solution in VS2010
